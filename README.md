# GophKeeper - Менеджер паролей

GophKeeper — это безопасный клиент-серверный менеджер паролей, созданный на Go, который позволяет пользователям надёжно хранить и синхронизировать конфиденциальную информацию, включая логины, пароли, бинарные данные и банковские карты.

## Возможности

### Сервер
- Регистрация и аутентификация пользователей
- Безопасное хранение данных
- Синхронизация нескольких клиентов
- Получение данных по запросу

### Клиент (CLI)
- Кроссплатформенность (Windows, Linux, macOS)
- Аутентификация пользователей
- Локальное и удалённое управление данными
- Информация о версии

## Поддерживаемые типы данных
- Пары логин/пароль
- Произвольные текстовые данные
- Бинарные данные
- Информация о банковских картах
- Метаданные для всех типов данных

## Начало работы

### Требования
- Go 1.21 или выше
- PostgreSQL 13+ (для хранения данных)

### Установка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd final

# Соберите сервер
cd cmd/server
go build -o gophkeeper-server

# Соберите клиент
cd ../client
go build -o gophkeeper-client
```

### Запуск сервера

```bash
./gophkeeper-server
```

Сервер запустится на `localhost:8080` по умолчанию.

### Запуск клиента

```bash
./gophkeeper-client
```

## Использование

### Команды клиента

```bash
# Отобразить информацию о версии
./gophkeeper-client version

# Зарегистрировать нового пользователя
./gophkeeper-client register

# Вход в систему
./gophkeeper-client login

# Добавить логин/пароль
./gophkeeper-client add login

# Список всех записей
./gophkeeper-client list

# Получить запись
./gophkeeper-client get <entry-id>

# Синхронизация с сервером
./gophkeeper-client sync
```

## Архитектура

- `cmd/server` - Серверное приложение
- `cmd/client` - Клиентское CLI приложение
- `internal/server` - Бизнес-логика сервера
- `internal/client` - Бизнес-логика клиента
- `internal/storage` - Слой базы данных
- `internal/models` - Общие модели данных
- `internal/crypto` - Утилиты шифрования

## Безопасность

- Пароли хешируются с использованием bcrypt
- Данные шифруются с использованием AES-256-GCM
- HTTPS/TLS для клиент-серверного взаимодействия
- JWT токены для аутентификации
